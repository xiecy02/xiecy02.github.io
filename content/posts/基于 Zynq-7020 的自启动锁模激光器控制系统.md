# 基于 Zynq-7020 的自启动锁模激光器控制系统 (mll_control) 开发全记录

## 一、 项目背景与架构演进

在自启动锁模激光器（Mode-Locked Laser, MLL）系统中，为了实现激光的脱机自主锁模，需要实时采集激光输出的特征参数，并依据自动化寻优算法实时调节硬件控制量（如偏振态、泵浦功率等）。

* **架构演进**：将原先基于纯 FPGA 逻辑（PL）的控制状态机迁移至 ARM 处理器（PS）端，利用 **FreeRTOS** 实时操作系统进行任务调度与编译运行。
* **软硬件协同**：PL 侧保留高速数据采集与特征提取逻辑；PS 侧运行自启动寻优算法（4D Lissajous 扫频 + LFSR 爬坡算法），实现典型的 **软硬件协同设计（Hardware-Software Co-design）**。

## 三、 完整开发步骤流程
[阶段一：Vivado 硬件平台搭建]
  1. 编写 PL 顶层逻辑与采样模块 (top_9434.v)
  2. Block Design 实例化 Processing System (PS)
  3. 配置 AXI GPIO 总线实现 PS/PL 寄存器映射
  4. 综合、实现、生成比特流 (top_9434.bit)
  5. 导出硬件平台描述文件 (.xsa)
       │
       ▼
[阶段二：Vitis 软件与算法开发]
  1. 基于 .xsa 自动生成 Platform (包含 zynq_fsbl)
  2. 新建 FreeRTOS Application 工程 (mll_control)
  3. 编写/优化 C 代码 (mll_controller.c)
  4. 部署 4D Lissajous 扫频与 LFSR 爬坡寻优算法
  5. 编译链接出可执行文件 (mll_control.elf)
       │
       ▼
[阶段三：板级在线联合调试]
  1. JTAG 连接开发板，开启波特率 115200 串口
  2. 执行 Program Device 将 .bit 烧写进 PL
  3. 执行 Run As Launch Hardware 将 .elf 运行于 PS
  4. 串口观察 4D 扫频与锁模状态转移日志
       │
       ▼
[阶段四：BOOT.BIN 打包与 Flash 脱机固化]
  1. 打开 Create Boot Image 界面
  2. 按顺序添加：fsbl.elf -> top_9434.bit -> mll_control.elf
  3. 生成 BOOT.BIN 文件
  4. 打开 Program Flash 工具将 BOOT.BIN 写入 QSPI Flash
  5. 调整开发板拨码开关至 QSPI 启动模式，实现脱机自启动
